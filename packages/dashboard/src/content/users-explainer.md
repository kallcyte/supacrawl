# How the Users page works

Manage who can access the dashboard. This page is only visible to admins.

## Creating a user

Use the **New user** toggle to open the form. Enter an email, a password (at least 8
characters), an optional name, and pick a **Role**.

## Roles

- **Admin** — full control: can manage crawl jobs, monitors, users, notification
  channels, and settings.
- **User** — can view monitors, crawls, and history, and set their own notification
  preferences.

You can change a user's role inline from the table. The role change applies
immediately.

## Deleting a user

Remove a user with the delete button. They will no longer be able to access the
dashboard, and this cannot be undone.

## Limitations

- You **cannot delete or demote yourself** — your own row is marked with a **you**
  badge and its controls are disabled, so you can't lock yourself out.
